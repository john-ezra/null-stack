# Development policy

No formal development lifecycle is selected for this project. No task workflows are selected. Work on the user's requested task under the project guides; do not require a skill library, tracker, or lifecycle artifact to begin.

Do not infer tracker records, artifact homes, approval stages, or task transitions. When a request needs a document destination or permission that it does not supply, resolve that before writing. Reading guidance or approving content does not authorize execution or publication. Follow [project write restrictions](../AGENTS.md#rules).

Before Git or PR work, read [Git conventions](GIT.md). Before Linear access, read [Linear context](LINEAR.md). Before designing, changing, or reviewing an area, or maintaining a decision record, read [design decisions](design-decisions/README.md). Before the first code or documentation edit in a session, read [code style](CODE-STYLE.md).

Complete the requested scope and report the result, verification performed, and any unmet requirement. Finishing the task does not authorize a commit, PR, merge, tracker transition, or further work. Follow a task workflow only when the user explicitly requests it; that request does not select a project-wide lifecycle.

# Linear context

No Linear integration is configured for this project. Ordinary project work does not require Linear access or tracker records.

For an explicit Linear request, confirm the intended workspace, team, and any project or record destination before accessing project records. Use destinations confirmed by the user; an authenticated account, CLI default, or similarly named project is not evidence of the right destination. Ask the user when the request does not identify it unambiguously.

Follow [project write restrictions](../AGENTS.md#rules) for any record changes. Authorization to read a record does not authorize a write, and approval of draft content does not authorize publication or a state transition.

Preserve existing labels, priority, ownership, and state unless the request authorizes their change. Do not infer an assignee from the authenticated account. Confirm the destination's visibility before sending sensitive material; keep credentials and private material out of destinations not authorized to receive them.

For artifact placement and completion policy, read [development policy](DEVELOPMENT.md). A Linear request does not adopt a lifecycle or authorize integration setup.

# Toolkit design decisions

This directory holds lasting decisions about the public toolkit. Before designing, changing, or reviewing an area, list the sibling decision files and read the ones that govern it. When changing how decisions are recorded, read [Design decision records](design-decision-records.md).

For reading, writing, or revising a decision, follow [the shared decision-record guidance](../../Skills/software-design/DECISIONS.md). Records live beside this guide at `<slug>.md`; the shared guidance owns their format and maintenance rules.

Keep rationale that toolkit users need in this public repository, with sources they can access. Private project-administration decisions belong in their owning workspace, not here. Each decision has one home; do not mirror records across repositories.

The [project starter's guide](../../Templates/Project/agent-docs/design-decisions/README.md) is source material for consuming projects, not this toolkit's record home. These toolkit records require neither a workflow nor Linear.
